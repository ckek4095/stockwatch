# Stockwatch · акции США

Telegram-бот на Python: личный список американских акций, цены в долларах и
сводка по команде. Источник котировок — **Finnhub**.
Finnhub — поставщик данных; поддерживаемый рынок — листинги США.

## Команды

| Команда           | Результат                                                             |
| ----------------- | --------------------------------------------------------------------- |
| `/start`, `/help` | Справка                                                               |
| `/add AAPL`       | Добавить Apple в личный список                                        |
| `/remove AAPL`    | Удалить акцию                                                         |
| `/list`           | Свой список                                                           |
| `/quote MSFT`     | Последняя доступная цена Microsoft и изменение к предыдущему закрытию |
| `/summary`        | Сводка по избранному                                                  |
| `/delete_me`      | Удалить своё избранное                                                |

Тикеры нечувствительны к регистру. До 20 акций на пользователя. Например:
`AAPL`, `MSFT`, `NVDA`, `AMZN`. Точки и дефисы допускаются, но нужно использовать
точный `symbol` из Finnhub: бот не переименовывает тикер автоматически.

Поддерживаются `Common Stock` и `ADR` из каталога `exchange=US` с валютой `USD`.
ETF, опционы, криптовалюта и другие рынки в эту версию не входят (потом мб добавлю). Отсутствие
тикера в этом каталоге не означает, что инструмент вообще не существует.

Бот работает только в личных сообщениях. Списки пользователей изолированы
и сохраняются после перезапуска. Предусмотрен allowlist числовых Telegram ID.

В этой версии нет автоматических рассылок, пороговых сигналов, торговли,
подключения брокерского счёта, прогнозов, графиков и платежей. Сводка выдаётся
по запросу. Изменение цены акции не равно доходности пользовательского портфеля.
